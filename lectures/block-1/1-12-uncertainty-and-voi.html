Lecture 1.12

Uncertainty: probabilistic sensitivity analysis and value of information

Block 1 · Foundations, burden of disease and health economics
The point

Every model input is uncertain, so every model answer is uncertain. This lecture shows how to carry input uncertainty through to the decision (probabilistic sensitivity analysis), show how sure the decision is (acceptability curves), and put a price on resolving the uncertainty (value of information). The last step is where Project 1 uses an ML metamodel: it tells Saudi decision-makers which missing data, such as true compliance, would be most worth collecting.

1. Three kinds of uncertainty

Uncertainty comes from the numbers you put in, the shape of the model, and the analytic rules you chose, and each needs a different tool.

KindPlain meaningSalt exampleHandled by
ParameterWe don’t know the true value of an inputHow much does 1 g less salt lower blood pressure?Probabilistic sensitivity analysis
StructuralWe don’t know the right model shapeDoes the effect of salt on blood pressure differ by age? Are diseases independent?Scenario analyses with alternative structures
MethodologicalAnalysts disagree on the rulesDiscount rate, perspective, thresholdA reference case, plus scenarios
Why it matters
A model that reports one number hides how fragile it is. Decision-makers need to know whether the answer would change if the inputs were a bit different.
How to tell
Ask whether more data on an input would settle it (parameter), whether it is about how the model is built (structural), or whether it is a value choice no data can settle (methodological).
Trap

Confusing uncertainty with variability and heterogeneity. Variability is chance differences between identical people (one has a stroke, one doesn’t). Heterogeneity is explained differences between groups (men and women have different stroke rates). Neither is uncertainty. Handle heterogeneity by running subgroups separately, not by widening the input distributions.

Example · Project 1

Compliance with the 2025 voluntary limits is a parameter uncertainty: a measurement would settle it. Whether to model industry reformulation costs is methodological (it depends on perspective). Whether salt affects non-nationals and nationals the same way is structural, and becomes a heterogeneity question in Project 8.

2. One-way and tornado analysis

Deterministic sensitivity analysis changes one input at a time to its plausible low and high values and records how much the result moves.

What it is
One-way: vary one input, hold the rest at their best estimates. A tornado diagram shows a horizontal bar per input, its width the range of results, sorted widest at the top. Threshold analysis asks how far an input must move before the decision flips.
Why it matters
It is quick and easy to explain. It shows which inputs the result leans on, which guides where to look harder.
How to read it
A wide bar that crosses the threshold (or zero net benefit) means that input can change the decision. A wide bar that stays on one side changes the size of the answer but not the decision.
Trap

Treating a tornado diagram as the full picture of uncertainty. It moves inputs one at a time, so it misses what happens when several are unfavourable together, and its ranges are often chosen arbitrarily. It ranks inputs; it doesn’t tell you how likely the decision is to be wrong. That needs PSA.

Example · Project 1 (illustrative)

A threshold analysis might ask: how low can compliance with the bread limit fall before the policy is no longer cost-saving? If the answer is “below 10%”, the conclusion is robust. If it is “below 70%” and measured compliance is near that, the decision hinges on enforcement.

3. Probabilistic sensitivity analysis

Probabilistic sensitivity analysis (PSA) gives every uncertain input a probability distribution, draws all inputs at once, runs the model, and repeats thousands of times.

What it is
Each run uses one plausible set of inputs and gives one cost and one health result per option. Thousands of runs give a cloud of results that reflects all the input uncertainty together. Distributions are chosen to fit the kind of input: beta for probabilities (bounded 0–1), gamma or lognormal for costs (positive, skewed), lognormal for relative risks.
Why it matters
It answers the question one-way analysis can’t: given everything we don’t know, how likely is this option to be the best? Most guidelines and journals expect it, and it is the input for value of information.
How to read it
Plot the runs on the cost-effectiveness plane (Lecture 1.10). A tight cloud in one quadrant means a confident answer. A cloud spread across quadrants, or straddling the threshold line, means the decision is uncertain. Report the mean across runs as the main result.
What a change means
Narrowing one input’s distribution (say, after a new meta-analysis) shrinks the cloud only as far as that input drove the spread.
A PSA cloud on the cost-effectiveness plane

Each dot is one model run: a new salt policy against current practice. Narrow one source of uncertainty at a time and watch which way the cloud shrinks. Then move the threshold.

Trap

Drawing linked inputs independently. Baseline risk and a relative risk from the same regression, or the probabilities of leaving one state, are correlated or must add up to one. Drawing them separately produces impossible combinations. Draw them jointly (for example from a multivariate normal or a Dirichlet distribution).

Example

In a statin model, the relative risk of heart attack might come from a meta-analysis as 0.75 (95% CI 0.70–0.80). Rather than plugging in 0.75, PSA draws a new value each run from a lognormal distribution matching that interval, so the uncertainty in the trial evidence flows into the final result.

From your ML background

PSA is Monte Carlo forward propagation of parameter uncertainty, the same idea as sampling from a posterior and pushing each draw through a model to get a predictive distribution. Input distributions play the role of priors or posteriors; outputs are a sample, not a point estimate.

4. Acceptability curves

A cost-effectiveness acceptability curve (CEAC) shows, for each possible threshold, the probability that each option is the most cost-effective.

What it is
For a given threshold, compute net monetary benefit (Lecture 1.10) for each option in every PSA run, and count the share of runs in which each option wins. Repeat across a range of thresholds and plot.
Why it matters
It answers the decision-maker’s question without forcing one threshold, which suits countries like Saudi Arabia with no single agreed threshold.
How to read it
A curve near 1 means the option is almost surely best at that threshold. A curve near 0.5 between two options means it is close to a coin toss. At very low thresholds the cheapest option tends to win; at high thresholds, the most effective.
What a change means
A rise from 0.6 to 0.9 as the threshold increases means the option becomes clearly worth it once each DALY is valued more. A flat curve means the decision barely depends on the threshold.

The interactive in section 5 draws this curve from simulated runs and lets you test the trap below.

Trap

Choosing the option with the highest probability of being cost-effective. The right choice is the one with the highest expected net benefit. When results are skewed, an option can win in 60% of runs by a little but lose in 40% by a lot. The cost-effectiveness acceptability frontier marks the option with the highest expected net benefit at each threshold.

Analogy

A bet that wins 60% of the time and pays 1 riyal, but loses 10 riyals the rest of the time. It usually wins, and it is still a bad bet.

5. Value of perfect information

The expected value of perfect information (EVPI) is the most it would be worth paying to remove all uncertainty before deciding.

What it is
In each PSA run, imagine you knew that run’s inputs were true and picked the best option for them. Average those best outcomes. Then compare with what you get by picking the one option that is best on average today. The gap, in net benefit, is EVPI: the expected loss from deciding under uncertainty.
Why it matters
It sets an upper bound on the value of more research. Multiply the per-person EVPI by the number of people the decision affects over its lifetime to get the population EVPI. If that is below the cost of any feasible study, decide now; more research can’t pay off.
How to read it
EVPI is zero when the same option wins in every run: there is nothing to learn that would change the decision. It is highest when the decision is close (the ICER is near the threshold) and uncertainty is large.
What a change means
A large population EVPI says research could be worth it, not which research. That is the next section.
Acceptability curve and EVPI

Move the threshold towards and away from the ICER (20,000) and watch EVPI rise and fall. Then switch to skewed costs and set the threshold to 18,000.

Trap

Reading high uncertainty as high EVPI. Inputs can be very uncertain and EVPI still near zero, if every plausible value leads to the same decision. A cost-saving policy that stays cost-saving across the whole PSA has no value of information, however wide its confidence intervals.

Analogy

The most you would pay for a perfect weather forecast before a wedding. Worth a lot if the venue is outdoors and the season is unsettled. Worth nothing if you are indoors anyway.

6. Which uncertainty matters: EVPPI

The expected value of partial perfect information (EVPPI) is the value of learning one input, or a group of inputs, exactly, with everything else still uncertain.

What it is
The same logic as EVPI, applied to a subset of inputs. It is what you would gain from a study that measured, say, compliance perfectly while leaving the other inputs as they are.
Why it matters
It ranks research priorities by their effect on the decision, not by how uncertain the inputs look. Groups of inputs that would be measured in the same study (e.g. all costs) should be assessed together.
How to read it
Compare EVPPIs across inputs. The input with the largest EVPPI is where research would pay most. The expected value of sample information (EVSI) goes one step further: the value of a real study of a given size, which can be set against what the study costs.
Trap

Adding EVPPIs. The EVPPIs of separate inputs don’t add up to the EVPI, or to the EVPPI of the group. Uncertainties interact through the decision. Compute the group directly.

Example · Project 1 (illustrative)

Suppose EVPPI is high for compliance with the voluntary limits and near zero for stroke treatment costs. The message to SFDA is: measuring how much salt manufacturers actually removed is worth more than a new costing study. That is a concrete, decision-linked reason to collect the data Project 9 explains.

7. Metamodels for EVPPI

Regression-based EVPPI fits a fast statistical model (a metamodel) to the PSA output, so you can estimate EVPPI from the PSA you already ran instead of running the model millions more times.

What it does
EVPPI needs, for each value of the input of interest, the expected net benefit averaged over all other inputs. The direct way nests a second simulation inside each draw, which is very slow. Strong, Oakley & Brennan (2014) showed you can regress each option’s net benefit on the input of interest across the PSA runs. The fitted values estimate that average; the leftover noise is the other inputs, which is exactly what you want to average out.
Which metamodel
For one to a few inputs, a generalised additive model (GAM: flexible smooth curves). For larger groups, a Gaussian process. Other flexible learners work in principle. The SAVI web tool and the voi and BCEA R packages implement the standard methods.
How to read it
Check the metamodel fit as you would any regression: residual plots, and the standard error of the EVPPI estimate. Then read the EVPPI as in section 6.
What a change means
More PSA runs give a more precise EVPPI. If adding runs moves your EVPPI ranking, you didn’t have enough.
Trap

An overfitted metamodel inflates EVPPI. If the fitted values chase noise from the other inputs, they vary more than the true average does, and the method reads that spurious variation as decision-relevant information. Underfitting does the opposite. Choose flexibility by cross-validation or the model’s own smoothing, not by maximising fit.

From your ML background

The metamodel is estimating a conditional expectation, the expected net benefit given the input of interest, which is exactly what squared-error regression targets. So any well-regularised learner fits the framework. The ML-specific risk is the one above: on this task variance doesn’t average away, it adds bias upwards, because the method takes a maximum over the fitted values.

Second use: emulators

A metamodel can also stand in for a slow simulator, so you can run PSA or calibration on the fast surrogate. Gaussian process emulators are the classic tool. A PMSLT like Project 1 usually runs fast enough that you won’t need this, but large microsimulations do.

Check yourself

  1. A tornado diagram shows the salt–blood pressure effect has the widest bar, but the bar never crosses zero net benefit. What does this tell you, and what does it not tell you?

    Show answer

    That input moves the size of the benefit most, but on its own it can’t flip the decision. It doesn’t tell you what happens when several inputs are unfavourable together, or how likely the decision is to be wrong. PSA answers those.

  2. Why should men and women be run as separate subgroups rather than having sex folded into a wider input distribution in the PSA?

    Show answer

    Sex differences are heterogeneity: known, explained differences, not uncertainty about a value. Folding them into the PSA makes the result look more uncertain than it is and hides that the answer may differ by group. Run subgroups separately, each with its own PSA.

  3. At a given threshold, option A is cost-effective in 65% of PSA runs and option B in 35%, but B has the higher expected net benefit. Which do you recommend?

    Show answer

    B. The decision rule is highest expected net benefit. A wins more often by small margins, while B wins by large margins when it wins. The acceptability frontier would mark B at that threshold.

  4. Your salt policy is cost-saving in 99% of PSA runs, yet the confidence interval on blood-pressure effects is wide. A colleague wants to fund a new trial to narrow it. What does value of information say?

    Show answer

    EVPI and the EVPPI for that effect will be close to zero, because almost every plausible value leads to the same decision. A new trial would sharpen the size of the benefit but would almost never change the choice, so on decision grounds it isn’t worth funding. It might still have scientific value.

  5. You fit a deep neural network to estimate EVPPI from 2,000 PSA runs, and it gives a much higher EVPPI for compliance than a GAM does. Which do you trust, and why?

    Show answer

    Be suspicious of the network. With 2,000 runs, a very flexible model can overfit, and overfitting inflates EVPPI. Check both with held-out data or cross-validation and look at the residuals. If the GAM fits as well out of sample, prefer it; if the network genuinely fits better, more PSA runs should confirm the higher figure.

  6. What would make population EVPI for Project 1 large, and what would you do with that finding?

    Show answer

    A decision close to the threshold, wide uncertainty in inputs that drive it, and a large population affected for many years. A large EVPI justifies further research, and EVPPI then points to which input to study, for example measuring compliance or baseline salt intake. Project 2’s pooled intake estimate is one way to reduce that uncertainty.
