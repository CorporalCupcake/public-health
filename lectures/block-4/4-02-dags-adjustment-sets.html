Lecture 4.2

DAGs and choosing adjustment sets

Block 4 · Causal inference and policy evaluation
The point

Lectures 2.6 and 2.7 introduced confounders, colliders and backdoor paths. This lecture turns that into a procedure: read every path between treatment and outcome, decide which are open, and choose a set of covariates that closes the non-causal ones without blocking the causal ones. It also covers the variables that look like sensible adjustments and are not: mediators, colliders, descendants of treatment, M-structures and instruments. The adjustment set you choose here is the input to every estimator in Lectures 4.3–4.5, and to the protocol for Project 5A.

1. d-separation in practice

Association flows along any path between two variables, whatever direction the arrows point, unless something on the path blocks it.

What it is
A path is any sequence of edges joining two variables, ignoring arrow direction. Two variables are d-separated by a set \(Z\) when every path between them is blocked. A path is blocked if it passes through a non-collider that is in \(Z\), or through a collider that is not in \(Z\) and has no descendant in \(Z\).
Why it matters
d-separation is the bridge from a drawing to the data: if the DAG is right, d-separated variables are independent given \(Z\). That is what makes “adjusting for \(Z\) removes confounding” a checkable claim about the graph rather than a hope.
How to read it
Walk each path node by node. At a chain (→ M →) or fork (← C →), the path is open unless you condition on the middle node. At a collider (→ K ←), it is closed unless you condition on K or anything K causes.
What a change means
Adding one variable to \(Z\) can close some paths and open others at the same time. That is why “adjust for more” is not a monotone improvement.
StructureLeft aloneConditioned on the middle node
Chain: A → M → YOpen (carries effect)Closed (the mediated part is removed)
Fork: A ← C → YOpen (carries confounding)Closed
Collider: A → K ← YClosedOpen, and so is conditioning on any descendant of K
Trap

Thinking that only paths that follow the arrows matter. Association does not care about direction: A ← C → Y transmits association just as well as A → Y. Direction decides only which paths are causal (all arrows pointing away from the treatment) and which are biasing.

From your ML background

This is the same d-separation that defines conditional independence in a Bayesian network. The difference is the reading of the arrows: in a Bayes net any factorisation consistent with the data will do, while in a causal DAG each arrow is a claim about what would change under intervention. Two DAGs can imply the same independencies and give opposite adjustment advice.

2. The backdoor criterion and minimal adjustment sets

A set of covariates is enough to estimate the total effect if it blocks every backdoor path and contains nothing caused by the treatment.

What it is
A backdoor path starts with an arrow into the treatment. The backdoor criterion says a set \(Z\) is sufficient for the total effect of A on Y if (1) no member of \(Z\) is a descendant of A, and (2) \(Z\) blocks every backdoor path. A minimal sufficient set is a sufficient set from which no variable can be removed.
Why it matters
It turns “which confounders?” into a question with an answer, given the DAG. It also shows there is often more than one valid answer, so you can choose the set whose variables are best measured, least missing or cheapest to collect.
How to read it
Sufficiency is a property of the whole set, not of single variables. A variable can be needed in one set and unnecessary in another. If a minimal set contains a variable you did not measure, look for an alternative set that avoids it before giving up.
What a change means
Adding a pure cause of the outcome to a sufficient set keeps it sufficient and usually improves precision. Adding a pure cause of the treatment keeps it sufficient but costs precision (section 4).
Choose an adjustment set for Project 5A

Click a node to adjust for it (click again to undo). Every path from anticoagulation to death is listed below with its state. Aim for a set that closes every backdoor path while leaving both causal paths open. Then try adding Transfusion or Major bleed and see what breaks.

library(dagitty)
g <- dagitty("dag {
  Age -> Anticoag ; Age -> Death
  Severity -> Anticoag ; Severity -> Death ; Severity -> Transfusion
  BleedRisk -> Anticoag ; BleedRisk -> Bleed ; Preference -> Anticoag
  Anticoag -> Bleed ; Bleed -> Death ; Bleed -> Transfusion
  Anticoag -> Death
}")
adjustmentSets(g, exposure = "Anticoag", outcome = "Death")  # minimal sets
paths(g, "Anticoag", "Death", Z = c("Age", "Severity"))    # open or closed
impliedConditionalIndependencies(g)    # what the data should show if g is right

This writes the widget’s DAG in dagitty’s syntax, asks for every minimal sufficient adjustment set for the total effect, lists each path with whether it is open given a candidate set, and prints the conditional independencies the DAG implies. localTests(g, data) then checks those against your data.

Example · Reading the widget’s answer

In this DAG the only minimal sufficient set is {age, illness severity, bleeding risk}. Bleeding risk is needed even though it has no arrow into death: the path Anticoag ← Bleeding risk → Major bleed → Death is open until you block it, and you cannot block it at Major bleed because that is on the causal path. Variables that matter only through another route are easy to drop by mistake.

Analogy

Sealing a house against draughts. You need to close every gap that lets outside air in (backdoor paths) without bricking up the front door you actually want to use (the causal paths). Any set of seals that does this works; you choose the ones easiest to fit.

3. Bad controls after treatment, and the Table 2 fallacy

For a total effect, never adjust for anything the treatment could have caused: mediators remove part of the effect, and colliders or their descendants create new bias.

What it is
A mediator lies on a causal path (Anticoag → Major bleed → Death). A descendant of treatment is anything downstream of it, including variables that are also caused by other factors (Transfusion, caused by bleeding and by severity). Conditioning on such a variable can open a collider path between treatment and an outcome cause.
Why it matters
In clinical data, post-treatment variables look like ordinary covariates: day-3 creatinine, transfusion, length of stay. Adjusting for them “to account for how sick patients became” is one of the commonest errors in EHR studies, and it can push an estimate in either direction.
How to read it
For each covariate, ask: could the treatment have changed it? If yes, and you want the total effect, leave it out. If you want a direct effect, that is a different estimand with its own assumptions (Lecture 4.10).
What a change means
An estimate that moves towards the null when you add a post-treatment variable is not “more conservative”; it answers a different, usually ill-defined, question.
Trap · The Table 2 fallacy

Reading every coefficient in the adjusted model as an effect. The model was built so that the treatment’s coefficient is causal. For age or severity, the same model may adjust for their mediators (the treatment itself) and omit their confounders. Westreich and Greenland (2013) named this the Table 2 fallacy. Report the treatment effect; if another variable’s effect matters, build a separate DAG and model for it.

Example · Adjusting for transfusion

Suppose an analyst adds “received a transfusion” to the Project 5A model to capture how sick patients were. Anticoagulation causes bleeding, bleeding causes transfusion, and severity also causes transfusion. Among transfused patients, an anticoagulated patient was more likely transfused because of a bleed, and an untreated one because of severe illness. So within that group, anticoagulated patients tend to be less severely ill, and the estimate is pushed towards benefit for reasons that have nothing to do with the drug. Toggle Transfusion in the widget to see the path open.

4. Bad controls before treatment: M-bias and instruments

Being measured before treatment does not make a variable safe to adjust for, but the pre-treatment traps are usually smaller than the confounding you risk by leaving real confounders out.

What it is
M-bias: a pre-treatment variable that is a collider between an unmeasured cause of treatment and an unmeasured cause of the outcome; adjusting for it opens a path. An instrument affects the outcome only through treatment (prescriber preference, distance to a specialist centre). Adjusting for an instrument closes no backdoor path, increases variance, and amplifies any confounding that remains: bias amplification.
Why it matters
The two traps pull in opposite directions from the advice “adjust for all pre-treatment variables”. Knowing when they matter stops you from both over-adjusting and using them as an excuse to drop real confounders.
How to read it
Greenland (2003) and Ding and Miratrix (2015) showed M-bias is usually small unless the links are very strong, and that when the M-variable is also a confounder (the “butterfly”), adjusting usually leaves less bias. Bias amplification grows with the instrument’s strength and with how much confounding is left unmeasured (Myers and colleagues, 2011).
What a change means
If adding a strong predictor of treatment that has no plausible link to the outcome moves your estimate a lot, suspect amplification of residual confounding, not newly removed bias.
A practical rule when the DAG is uncertain

VanderWeele’s (2019) modified disjunctive cause criterion: adjust for each pre-treatment covariate that is a cause of the treatment, the outcome or both; remove any known instrument; and include good proxies for unmeasured common causes. It works whenever some subset of the measured variables is sufficient, without needing the full DAG.

From your ML background

If you build a propensity model by throwing in every feature that predicts treatment, you will reward instruments: they predict treatment best precisely because they do nothing else. A higher AUC then buys more variance and amplified bias, not less confounding. The propensity model’s job is to balance confounders, not to predict treatment well (Lecture 4.3).

5. The front-door criterion

When confounding cannot be blocked but the whole effect runs through a measured mediator that is itself unconfounded, the effect can still be identified, in two steps.

What it is
Pearl’s front-door criterion: if a mediator M intercepts every causal path from A to Y, nothing unmeasured confounds A and M, and every backdoor path from M to Y is blocked by A, then you can estimate A → M, then M → Y adjusting for A, and chain them. Pearl’s textbook example is smoking → tar in the lungs → cancer, with unmeasured genotype confounding smoking and cancer.
Why it matters
It shows identification is not only “adjust for confounders”: a different set of assumptions about the graph can identify an effect that the backdoor route cannot.
How to read it
Its conditions are strong and rarely all believable in epidemiology: the treatment must have no effect except through M, and M must be unconfounded with Y. Treat front-door claims with the same scrutiny as an instrument (Lecture 4.9).
Trap

Confusing front-door estimation with mediation analysis. Front-door uses the mediator to recover the total effect when confounding is unmeasured. Mediation analysis (Lecture 4.10) splits an already identified total effect into direct and indirect parts.

6. Confounders affected by earlier treatment, and SWIGs

When a covariate both confounds later treatment and is caused by earlier treatment, no adjustment set in an ordinary regression gives the effect of a treatment strategy; you need g-methods.

What it is
Treatment is decided repeatedly (A0, A1, …), and a time-varying covariate L1 sits between decisions: A0 affects L1, and L1 affects both A1 and the outcome. This is treatment–confounder feedback. Adjusting for L1 blocks part of A0’s effect and can open a collider path through unmeasured causes of L1; not adjusting leaves A1 confounded.
Why it matters
It is the normal situation in ICU and chronic-disease data. In Project 5A, daily anticoagulation decisions depend on platelet count and bleeding signs, which are themselves affected by earlier heparin. A Cox model with time-varying platelets cannot give the effect of “anticoagulate throughout”.
How to read it
Look for any covariate measured after baseline that both drives later treatment and could have been changed by earlier treatment. If you find one, the analysis needs inverse probability weighting of a marginal structural model or the g-formula (Lecture 4.3), or a design that fixes treatment at baseline (Lecture 4.5).
SWIGs
Single-world intervention graphs (Richardson and Robins, 2013) split each treatment node into what was observed and what is set by the intervention, so potential outcomes appear on the graph. You can then read conditions such as “\(Y(a)\) is independent of A given L” straight off it by d-separation. They are most useful for time-varying and dynamic strategies (“start anticoagulation if platelets stay above a threshold”).
Trap

“We adjusted for time-varying confounders in a time-dependent Cox model, so the estimate is causal.” That handles confounding of each day’s treatment only if no confounder is affected by earlier treatment. With feedback, the conditional hazard ratio mixes blocked effects and collider bias, and does not correspond to any treatment strategy.

7. Drawing a DAG you can defend

A DAG is a summary of subject knowledge, drawn before looking at the data and built so that reviewers can disagree with specific arrows.

What it is
Start from treatment and outcome. Add every common cause of any two variables already on the graph, measured or not; a causal DAG must include them. Order variables in time. Then use the graph to find adjustment sets, and the data only to check the independencies it implies.
Why it matters
Tennant and colleagues (2021) reviewed 234 health studies that used DAGs: only 62% showed at least one DAG, about half reported the adjustment set it implied, and about a fifth stated their estimand. A DAG in the supplement with a matching adjustment set is a reasonable reviewer request.
How to read it
The missing arrows are the claims. Every pair of nodes with no arrow asserts no direct effect. Check the ones a clinician would dispute. If you are unsure about an arrow, draw both versions and see whether the adjustment set changes; often it does not.
What a change means
If localTests shows a strong dependence the DAG says should not exist, an arrow or a common cause is missing. Fix the graph from subject knowledge, not by deleting the test.
Gulf example · A DAG for Project 4

For the sugary-drink taxes, the treatment is a country-year policy and the outcome is sugar supply per person. Common causes of tax timing and supply include fiscal pressure from oil prices, which also moves incomes and spending. Saudi Arabia and the UAE introduced 5% VAT on 1 January 2018, and Saudi Arabia raised its VAT to 15% on 1 July 2020: co-interventions that raise all prices and sit right next to the tax dates. Changes in the expatriate population move both the per-person denominator and dietary patterns. Drawing these before choosing a difference-in-differences specification (Lecture 4.6) tells you which ones parallel trends must survive.

Trap

Drawing the DAG from your variable list. The DAG must include what matters, measured or not; an unmeasured confounder you leave off the graph does not disappear, it just stops being argued about. Mark unmeasured nodes and say what you will do about them (proxies, bias analysis, Lecture 2.13).

Check yourself

  1. A colleague adds ICU length of stay to the Project 5A model because “longer stays mean sicker patients”. What is wrong?

    Show answer

    Length of stay is measured after treatment and is caused by it (bleeding prolongs stays) and by the outcome (death shortens them). Adjusting for it conditions on a descendant of treatment and a collider of treatment and outcome, which can create bias in either direction. Severity at baseline is the confounder; measure that instead.

  2. dagitty returns two minimal sufficient sets: {age, SOFA, bleeding risk} and {age, SOFA, platelets, prior bleed}. How do you choose?

    Show answer

    If the DAG is right, both remove confounding. Choose on measurement: which variables are recorded more accurately and completely, and which give more precision. Running both is a cheap check: if they disagree a lot, the DAG or the measurement is probably wrong somewhere.

  3. Hospital site strongly predicts whether patients are anticoagulated, but you believe it has no effect on death except through prescribing. Should it go in the propensity model?

    Show answer

    If that belief is right, site is an instrument: leave it out, because it adds variance and amplifies residual confounding. But sites also differ in case mix and quality of care, which affect death directly. If that is plausible, site is a confounder and should stay. This is a subject-matter judgement; state it, and consider showing both.

  4. A paper’s Table 2 lists adjusted odds ratios for the exposure, age, diabetes and smoking, and the discussion interprets each one. What do you say in review?

    Show answer

    Only the exposure’s coefficient was designed to be causal. The others are adjusted for variables that may be their mediators, and their own confounders were never chosen. This is the Table 2 fallacy: ask the authors to report only the exposure effect, or justify each secondary effect with its own DAG and model.

  5. Daily heparin lowers platelet counts in some patients, and low platelets make clinicians stop heparin and also predict death. Why can a Cox model with daily platelets as a time-varying covariate not give the effect of “anticoagulate throughout the ICU stay”?

    Show answer

    Platelets confound later heparin decisions, so they must be accounted for, but they are also affected by earlier heparin, so conditioning on them blocks part of the effect and can open collider paths through unmeasured causes of platelets. Ordinary regression cannot do both. IPW of a marginal structural model or the g-formula (Lecture 4.3) can.
